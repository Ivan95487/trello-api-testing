# trello-api-testing
Trello API Testing — QA Portfolio
About the Project
This is a beginner QA portfolio project focused on testing Trello REST API functionality.
The project demonstrates basic skills in API testing, test case design, test documentation, and working with testing tools.
Tools Used
Postman — API requests and automated checks
Jira — test case management
GitHub — project documentation and version control
Trello API — application under test

Test Coverage
The project includes 10 designed test cases covering:
Successful archiving of cards
Empty lists
Invalid list IDs
Authorization
Repeated requests
Lists with one or many cards
Data integrity of other lists
Invalid HTTP methods
Missing required parameters
Test Execution
Test cases have been designed in Jira.
Postman automated checks have been added to the collection. Actual execution results will be documented separately.
